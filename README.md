# Маяк — народная карта Владивостока

Карта города, которую наполняют жители, и агрегатор того, что о местах уже известно: отзывы,
оценки и фото из Яндекс Карт, 2ГИС и Google Maps собраны в одной карточке рядом с отзывами
самих жителей.


Проект хакатона «Вайбатон». Стек: **FastAPI + SQLAlchemy** / **React + TypeScript + 2ГИС MapGL**.

## Что умеет

**Одна карта, четыре слоя**

| Слой | Что на нём |
|---|---|
| Полезное | туалеты, вода, первая помощь, доступная среда, спортплощадки — с характеристиками по категории |
| События | афиша города и небольшие встречи с записью и лимитом мест |
| Интересное | места от жителей с описаниями и советами, маршруты |
| Проблемы | сообщения жителей и отключения воды, тепла, света |

**Отзывы из всех карт в одной ленте.** В карточке места — общий список: сверху отзывы жителей Маяка, дальше вперемешку Яндекс, 2ГИС и Google. У каждого отзыва значок источника и ссылка на оригинал. Фото открываются в просмотрщике: стрелки и клавиши на компьютере, свайп и щипок на телефоне.

**Сводная оценка.** Оценка места считается по Маяку и картам вместе: вес источника растёт с
числом оценок, голоса жителей весят вдвое больше. Разбивка по источникам видна в карточке.

**Локации.** Главный объект карты — место в широком смысле: «Нагорный парк», «Спортивная
набережная». У локации точный контур, оценка и список того, что внутри. Отдельные точки
сворачиваются в локацию и раскрываются при приближении.

**Тап в любую точку.** Открывается шторка: что это за объект, заметки жителей, что отмечено
рядом, быстрые действия — заметка, место, встреча, проблема.

**Маршруты.** Конструктор прогулок и походов: точки с описанием, ориентиром и фото, линия по
дорогам и тропам или напрямую. С собой — GPX, PDF с картой и QR-кодом, режим «Пройти маршрут».

**Доверие вместо ручной модерации всего подряд**

- Жители подтверждают или опровергают объекты; у публикации есть статус достоверности и история.
- У автора — репутация и уровень. Новички публикуются через премодерацию.
- Пользователь сам выбирает порог: показывать всё или только проверенное.
- Жалобы, автоматические проверки и LLM-предпроверка собирают очередь модератора с оценкой
  риска. Решение принимает человек, каждое пишется в журнал, автор может подать апелляцию.

## Как работает агрегация

1. Карточку открыли — бэкенд ищет это место в Яндекс Картах, 2ГИС и Google Maps.
2. Совпадение проверяют правила: название, расстояние, тип объекта. Где правила не уверены,
   решает LLM через OpenRouter. Каждое решение записывается с обоснованием.
3. Оценка, тексты отзывов, даты и ссылки кэшируются на 7 дней. Об авторах отзывов не хранится
   ничего, фото показываются по ссылке источника.
4. К источникам — не чаще запроса в 4 секунды и не больше дневного лимита. Капча или отказ
   завершают поиск для этого места, повтор через час.

## Быстрый старт

Нужен ключ 2ГИС (бесплатный демо-ключ: https://dev.2gis.com/). Ключ OpenRouter необязателен:
без него проверка контента работает на эвристиках, а сопоставление мест — только по правилам.

### Docker

```bash
cp .env.example .env      # вписать SECRET_KEY и TWOGIS_API_KEY
docker compose up --build
```

Приложение: http://localhost:8080. При первом запуске база заполняется демо-данными, затем в
фоне подтягиваются афиша и отключения.

### Локально

```bash
# бэкенд — http://localhost:8000
cd backend
cp .env.example .env      # вписать ключи
uv sync
uv run uvicorn app.main:app --port 8000

# фронтенд — http://localhost:5173
cd frontend
cp .env.example .env      # VITE_2GIS_KEY=...
npm install
npm run dev
```

### Основные настройки

| Переменная | Зачем |
|---|---|
| `SECRET_KEY` | подпись токенов, 32+ случайных символа |
| `TWOGIS_API_KEY` | карта, поиск адресов, геометрия объектов |
| `OPENROUTER_API_KEY` | LLM-предпроверка контента и сопоставление мест |
| `EXTERNAL_REVIEWS_ENABLED` | отзывы и оценки из Яндекса, 2ГИС и Google |
| `EXTERNAL_REVIEWS_PROXY_URL` | прокси только для запросов к источникам отзывов |
| `EXTERNAL_REVIEWS_DAILY_REQUEST_CAP` | лимит запросов к каждому источнику в сутки, по умолчанию 10 000 |
| `AFISHA_IMPORT_ENABLED`, `OUTAGES_IMPORT_ENABLED` | фоновый импорт афиши и отключений |

Полный список — в `.env.example`.

## Как устроено

```
docs/        SPEC.md — правила предметной области; API.md — HTTP-контракт; FRONTEND.md — дизайн и структура
backend/     app/domain — чистые правила (доверие, репутация, сводная оценка, геометрия) без БД и HTTP
             app/services — сценарии; app/services/experimental/external_reviews — агрегация отзывов
             app/api/v1 — тонкие роутеры; app/seed — демо-данные
frontend/    src/shared — дизайн-система, API-слой; src/features — разделы; src/app — оболочка
```

Подробности — в `backend/README.md` и `frontend/README.md`.

Основные решения:

- Всё на карте — «место» с общей карточкой, голосами и историей; события и проблемы расширяют
  его своими данными. Маршруты, локации и заметки — отдельные сущности.
- Статус достоверности считается из взвешенных голосов, жалоб и давности последней проверки и
  хранится отдельно от репутации автора.
- Сводная оценка не подменяет собственную: рейтинг Маяка, доверие и сортировка считаются только
  по голосам жителей.
- Автоматика только поднимает флаги: ни эвристики, ни LLM не публикуют и не удаляют контент сами.

## Источники данных и условия

| Источник | Что берём | Условия |
|---|---|---|
| 2ГИС | карта, поиск адресов, геометрия объектов | API по ключу, атрибуция на карте |
| Яндекс Карты, 2ГИС, Google Maps | отзывы, оценки, фото | сбор с открытых страниц нарушает условия сервисов; для промышленной эксплуатации нужно их разрешение или официальный API |
| OpenStreetMap | объекты, границы парков и площадей, линии маршрутов (OSRM от FOSSGIS) | ODbL, © участники OpenStreetMap |
| Викигид | места с описаниями, часы работы, адреса | CC BY-SA 4.0, подпись и ссылка у каждого текста |
| Wikimedia Commons, Википедия | фотографии и короткие описания | свободные лицензии, автор и лицензия показаны |
| VL.ru | афиша, отключения | открытые страницы в рамках `robots.txt`, со ссылкой; для эксплуатации нужно согласование |

## Ограничения прототипа

- SQLite и один процесс; миграций нет — после изменения моделей база пересоздаётся
  (`uv run python -m app.seed --reset`).
- «Загрузить ещё» из источника работает только для объектов карты 2ГИС (мосты, площади, парки); по остальным показывается до 30 отзывов с источника.
- Нет подтверждения e-mail и push-уведомлений; уведомления только внутри приложения.
- Демо-события, проблемы, отзывы жителей и заметки в начальных данных вымышлены.
